6. OPTIONAL: IF USING NGROK OR LOCALTONET THEN YOU CAN USE HTTPS FORCE SCHEME in App/Providors/AppServiceProvidor
7. COPY SHOPIFY APP PRIMARY KEY AND SECRET KEY
8. CHECK IF YOUR APP ON SHOPIFY HAVE ALL THE ACCESS REQUEST IN API ACCESS SECTION OF THE APP. ONLY NEEDED FOR PUBLIC APP

AT THE END:

9. php artisan serve
10. npm run dev
11. php artisan que:work
12. GO TO SHOPIFY APP AND INSTALL IT ON ANY STORE
13. AFTER INSTALLATION GO TO THEME CUSTOMIZATION (BEFORE FURTHER STEP FOLLOW BELOW)
13A. INSTALL RUBY ON YOUR PC
13B. GO TO EXTENSION FOLDER NAMED APPLICATION-EXTRENSIONS AND OPEN IT IN TERMINAL
13C. RUN COMMAND npm run deploy -- --reset
13D. LOGIN TO SHOPIFY IN TERMINAL (IF NOT LOGGED IN ALREADY) AND SELECT YOUR PARTNER WHERE YOUR APP IS CREATED
13E. SELECT YOUR APP AND PUSH YOUR EXTENSION CODE TO YOUR APP.
14. NOW YOU WILL SEE ALL OF THE APP EMBED AND APP BLOCKS OF THE INSTALLED APP. IN THEME CUSTOMIZATION.
15. ENABLE ALL OF THE THINGS
16. TO SETUP URLS'S OF APPLICATION ACCORDING TO DEVELOPMENT ENVIRONMENT. EMPTY THE applications table in all_in_one_conn DATABASE.
